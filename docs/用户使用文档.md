# 网络五子棋用户使用文档

## 1. 环境要求

- JDK 21
- IntelliJ IDEA
- MySQL 8.0 或更高版本
- Gradle（IDEA 自带的 Gradle 即可）

## 2. 数据库配置

默认配置位于 `src/main/resources/database.properties`：

```properties
database.enabled=true
database.host=localhost
database.port=3306
database.name=gomoku
database.user=root
database.password=root
```

将用户名和密码改成自己的 MySQL 配置即可。程序启动时会连接 MySQL，自动创建 `gomoku` 数据库，并执行 `src/main/resources/sql/init.sql` 中的建表语句。

项目当前默认连接参数为：

```text
地址：localhost
端口：3306
用户：root
密码：root
数据库名：gomoku
```

如果不希望连接数据库，可以将 `database.enabled` 改为 `false`。此时单机、人机和联机功能仍然可以使用，只是对局记录不会保存到数据库。

## 3. 在 IDEA 中启动游戏

1. 用 IDEA 打开 `D:\service\AAA-JAVA\gomoku`。
2. 等待 IDEA 识别 `build.gradle`。
3. 确认 Project SDK 为 JDK 21。
4. 运行 `io.github.tissyboxc.gomoku.Main`。

启动后显示 15 乘 15 棋盘、工具栏、状态区和聊天区。鼠标点击棋盘交叉点即可落子。

项目已经配置为离线构建。命令行构建时请使用本机 Gradle：

```text
D:\service\gradle-9.4.1\bin\gradle.bat --offline --no-daemon clean build
```

## 4. 本地双人模式

点击“本地双人”，黑棋先手。两位玩家共用同一台电脑轮流点击棋盘落子。

每次落子后程序会自动检查横、竖、正斜和反斜四个方向。出现五连时，界面会显示获胜提示，并用红线标出获胜连线。

## 5. 人机对战模式

点击“人机对战”，玩家执黑先手，电脑执白。

电脑落子时会短暂等待计算，完成后自动落子。AI 会优先寻找直接获胜点，再阻挡玩家的立即获胜点，最后使用棋型评分选择位置。

## 6. 联机对战

### 直接使用 BAT 启动

先执行一次构建：

```text
gradlew.bat clean build
```

构建完成后：

- 双击 `start-client.bat` 启动图形客户端
- 双击 `start-server.bat` 启动联机服务器

### 启动服务器

服务器程序同样是 `io.github.tissyboxc.gomoku.Main`，需要添加运行参数：

```text
server 9527
```

也可以在项目根目录执行（依赖包含 MySQL 驱动和编译输出）：

```text
java -cp 编译输出目录及依赖 io.github.tissyboxc.gomoku.Main server 9527
```

服务器启动后，两个客户端连接同一个 IP 和端口即可开始对局。服务器先安排两名玩家进入同一个房间，第一人执黑，第二人执白。

也可以直接使用 EXE：

```text
build\package-server\GomokuServer\GomokuServer.exe
```

### 打包为 EXE

双击项目根目录的 `build-exe.bat`，脚本会生成：

```text
build\package\Gomoku\Gomoku.exe
build\package-server\GomokuServer\GomokuServer.exe
```

第一个是图形客户端，第二个是带控制台窗口的联机服务器。EXE 已经包含 MySQL JDBC 驱动。

### 客户端连接

1. 客户端启动后会自动尝试连接 `127.0.0.1:9527`。
2. 如果服务器未启动，界面不会卡住，也不会弹出错误窗口，右侧大厅会显示“连接失败”。
3. 启动服务器后，点击大厅中的“连接服务器”即可重连。连接成功后按钮会变成“重连服务器”。
4. 第一次使用时输入用户名和密码，点击“注册”。注册成功后点击“登录”。
5. 本机测试时服务器地址保留 `127.0.0.1`。
6. 两台电脑测试时，在服务器一栏填写运行服务器电脑的局域网 IP，再点击“连接服务器”。

登录成功后，大厅会显示当前在线用户。双方可以按以下方式匹配：

- 随机匹配：点击“随机匹配”，服务器从等待队列中寻找另一位玩家。
- 固定匹配：在“指定用户”中输入对方用户名，点击“指定匹配”。对方界面会出现邀请，接受后立即开局。

每次匹配等待时间为 60 秒，界面会显示倒计时。等待期间可以点击“取消匹配”。超时后可以重新发起匹配。匹配成功后，发起者执黑，接受邀请的一方执白；随机匹配按进入等待队列的先后顺序分配黑白棋。

登录状态会一直保留在当前客户端中。切换到“本地双人”或“人机对战”时不会退出登录，也不会关闭服务器连接；程序只会取消正在进行的匹配并通知对手退出当前联机对局。切回“联机对战”后可以直接重新匹配，无需再次输入账号密码。

### 联机聊天

在右侧输入框中输入文字后按回车或点击“发送”。服务器会把消息广播给双方，并在聊天区显示发送者和内容。

### 联机悔棋

点击“申请悔棋”后，服务器把请求转发给对手。对手同意后，服务器回退一步，并同步更新双方棋盘和当前轮到的一方。

## 7. 悔棋

- 本地双人：点击“申请悔棋”直接回退一步。
- 人机对战：点击“申请悔棋”会回退玩家和电脑最近的落子，使局面回到玩家落子前。
- 联机：必须等待对方同意。

## 8. 更换背景和清屏动画

点击“更换背景”，可以选择“原木”“青玉”“海蓝”三套棋盘背景。

点击“清屏动画”，棋盘会播放一次扫光动画，并清空当前棋局。联机对局中，该按钮会发送重新开始请求，双方同意后清空服务器棋局。

## 9. 回放

### 保存回放

下棋过程中点击“保存回放”，对局会保存到项目运行目录的 `replays` 文件夹，文件名类似：

```text
gomoku-20260921-180000.gomoku
```

### 打开回放

点击“打开回放”，选择 `.gomoku` 文件。回放窗口支持：

- 第一步
- 上一步
- 下一步
- 最后一步
- 自动播放

## 10. 数据库内容

对局结束后，程序会使用 JDBC 保存：

- `game_record`：对局基本信息
- `game_move`：每一步落子
- `chat_message`：联机聊天内容
- `player_account`：注册用户名、密码摘要、盐值和最近登录时间

回放文件和对局数据库记录是两套记录方式，互不影响。

## 11. 常见问题

### 数据库初始化失败

检查 MySQL 是否启动、用户名和密码是否正确，以及当前账号是否具有创建数据库和创建表的权限。

### 联机连接失败

检查服务器程序是否启动、端口是否被占用、防火墙是否允许该端口，以及两台电脑是否在同一局域网。

### 没有声音或出现字体差异

本项目不依赖声音文件；棋盘和棋子由 Java2D 绘制。不同操作系统的 Swing 默认字体可能略有差异。
